# Employee Management System

A Java Maven-based console application for managing employees.

## Features

- Add Employee
- View Employees
- Update Employee
- Delete Employee
- Search Employee
- Unit Testing
- Maven Build
- Jenkins Integration

## Technologies

- Java 17
- Maven
- JUnit 5
- Git
- Jenkins

## Build

```bash
mvn clean package
```

## Test

```bash
mvn test
```

## Run

```bash
java -jar target/employee-management-system-1.0.0.jar
```
